Resource limits

How many MCP servers, tunnels, connected accounts and pending approvals each user may hold. Persisted values override the ENV defaults and apply at once; a per-user override (on the user's limits page) overrides both. 0 means unlimited. Existing resources above a lowered limit are kept; only new ones are refused.
