Install the mcp-gateway CLI

The command-line tool connects MCP servers that run on your own computer to this gateway: a stdio server your agent would normally start itself (for example npx -y some-mcp-server), or an HTTP server on localhost or your private network. It opens an outbound connection to the gateway, so nothing on your computer is exposed to the internet.

1. Install

{{template "install-tabs" .Data.Install}}

The install script detects your OS and CPU, downloads the latest release from GitHub Releases, verifies it against the release checksums, and installs mcp-gateway into ~/.local/bin without sudo (set INSTALL_DIR to change it, VERSION to pin a release). Windows: download the zip from GitHub Releases.

Check the install:

mcp-gateway version

2. Connect a local MCP server

  1. Sign in and open Servers. Under Tunnels, name the tunnel (for example laptop) and choose Create tunnel. Copy the token: it is shown once.
  2. Choose Add server and use the address tunnel://<tunnel id> shown next to the tunnel.
  3. On your computer, run the tunnel next to the server and leave it running: 
    {{.Data.StdioCommand}}
    or, for a local HTTP server: 
    {{.Data.HTTPCommand}}
  4. Back on the server's page, refresh it and approve the tools you want your agents to use. They then appear in every agent connected to the gateway.

The server is reachable only while the tunnel runs. Revoke a tunnel on the Servers page at any time. Run mcp-gateway tunnel --help for every option.
